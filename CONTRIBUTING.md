# Contributing

Use short-lived feature branches and conventional commits.

Examples:

- `feat(api): add stage recap endpoint`
- `feat(ios): add garage avatar preview`
- `fix(contract): correct activity pagination schema`
- `test(domain): cover sprint tie break`

Open a pull request with a focused change, passing CI, and at least one approval before merge. Use squash merge and delete merged branches.

Contract changes begin in `contracts/openapi.yaml` and include matching fixtures and tests.
